# Tasks

A simple, fast task manager built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Add tasks with a title, priority (low/medium/high), and optional due date
- Mark tasks complete, edit them inline (double-click a task), or delete them
- Filter by all / active / completed, and clear completed tasks in one click
- Overdue tasks are highlighted
- Everything persists to `localStorage` — no backend required
- Light and dark mode, responsive down to mobile widths

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build    # type-check and build for production
npm run lint      # run oxlint
npm run preview   # preview the production build locally
```
